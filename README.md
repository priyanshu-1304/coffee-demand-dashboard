# CoffeeForecastProject

This project contains a simple structure for a coffee sales forecasting application.

## Structure
- data/: place your Excel data files here
- notebooks/: analysis and experimentation notebooks
- pages/: Streamlit pages
- models/: trained models and artifacts
- images/: images and charts
- app.py: main Streamlit application entry point

## Setup
Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
